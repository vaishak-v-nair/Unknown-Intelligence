# Skeli Skills: Design Ideas & Inspirations

This skill organizes advanced web development design inspirations and machine-understandable UI/UX rules. Use this skill to synthesize visually stunning web layouts based on the reference sites provided by the user.

## Design Pillars

When applying `skeli-skills`, always evaluate designs against these core pillars:

1. **Visual Hierarchy & Layout**: Ensure clear distinction between primary, secondary, and tertiary elements. Emulate the clean, structured layouts of high-end dashboards.
2. **Typography**: Use modern, highly-legible fonts (e.g., Inter, Roboto). Maintain consistent tracking and line-height.
3. **Color Palette**: Follow the specific project color tokens. Support dynamic dark/light modes out of the box.
4. **Motion & Interaction**: Micro-interactions are required. Elements must respond fluidly to hover, focus, and click events.
5. **Responsiveness**: The UI must adapt seamlessly across mobile, tablet, and desktop breakpoints.
