description: Explain what just happened in plain English — no jargon
---

Re-explain your most recent answer and work for someone who does not read
code. Cover, in this order:

1. What was asked, in one line.
2. What you actually did or changed — describe files by what they do ("the
   login page code"), never by path.
3. Why it's better now, in outcome terms (faster, safer, fixed, prettier).
4. Anything the user must do or check now, if anything.

Rules: no jargon — if a technical word is unavoidable, define it in
parentheses right there. Maximum 8 short lines. No code blocks unless the
user asks. If you changed nothing, say so plainly.
